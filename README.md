# 📦 Margin x Padding — Introdução ao CSS

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

Exercício de introdução ao CSS para entender o **Box Model** e a diferença entre:

- **`margin`** — espaço **fora** da borda do elemento
- **`padding`** — espaço **dentro** da borda, entre a borda e o conteúdo

## 🚀 Como executar

Abra `introdução -css/index.html` no navegador.
